# Sources graphiques

Les fichiers de ce dossier servent à produire les ressources distribuées dans
`public/`. Ils restent versionnés, mais ne sont ni déployés ni embarqués dans
l'application Android.

- `branding/app-icon-source.png` : original de l'icône, conservé pour les futures
  générations. Les petits logos de l'interface utilisent `public/icons/icon-192.png`.
- `showcase/` : captures et animations historiques, conservées comme sources de
  présentation. L'accueil actuel compose son téléphone en HTML/SVG.

Les captures nécessaires à l'aide et les données pédagogiques restent dans
`public/` pour fonctionner hors connexion.
